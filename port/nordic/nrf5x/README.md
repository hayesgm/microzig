# Nordic nRF5x

HALs and register definitions for `nrf5x` devices

## Supported Chips:

- [nNF52840](https://www.nordicsemi.com/Products/nRF52840)
- [nRF52832](https://www.nordicsemi.com/Products/nRF52832)
- [nRF52833](https://www.nordicsemi.com/Products/nRF52833)

## Supported Boards:

- [nRF52840-MDK(https://wiki.makerdiary.com/nrf52840-mdk/) + nRF52840-Dongle
- [nRF52-PCA10040](https://docs.nordicsemi.com/bundle/ncs-1.2.1/page/zephyr/boards/arm/nrf52_pca10040/doc/index.html)
- [DWM3001CDK](https://www.qorvo.com/products/p/DWM3001CDK)
